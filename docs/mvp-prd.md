# 건강검진 기반 영양제 최적화 서비스 MVP PRD

## 1. 목표
- 사용자가 현재 복용 중인 영양제를 입력하면 영양성분을 일일 총량으로 계산한다.
- 건강검진 수치를 반영해 성분별로 `유지/증량/감량`을 제안한다.
- 추천 근거를 함께 보여 사용자 신뢰도를 높인다.

## 2. 타깃 사용자
- 이미 영양제를 복용 중이지만 과다/중복 여부를 모르는 사용자
- 건강검진 결과를 받았고 영양제 조정이 필요한 사용자

## 3. 핵심 사용자 시나리오
1. 사용자가 영양제 제품명(텍스트)을 입력한다.
2. 사용자가 라벨 이미지 OCR 텍스트를 붙여 넣는다.
3. 사용자가 건강검진 값(비타민D, LDL, HbA1c, 페리틴)을 입력한다.
4. 서비스는 성분별 총섭취량과 권장량/상한 비교 결과를 보여준다.
5. 서비스는 성분별 추천(유지/증량/감량)과 근거를 노출한다.

## 4. MVP 범위
- 포함
  - 제품명 기반 성분 매핑(내장 샘플 DB)
  - OCR 텍스트 기반 성분 파싱
  - 단위 정규화(mg, mcg, IU 일부)
  - 건강검진 값 기반 룰 엔진 추천
  - 결과 리포트 UI
- 제외
  - 실시간 외부 제품 DB 연동
  - 실제 이미지 OCR API 연동
  - 의사/약사 상담 연결
  - 개인 질환/복약 기반 고급 상호작용 엔진

## 5. 추천 로직 v1
- 기본 규칙
  - `총섭취량 < 권장량` -> 증량 후보
  - `총섭취량 > 상한섭취량` -> 감량 후보
- 검진 가중치
  - 비타민D < 20ng/mL -> 비타민D 증량 우선
  - LDL >= 160mg/dL -> 오메가3 보강 후보
  - 페리틴 < 30ng/mL -> 철 결핍 위험
  - 페리틴 > 300ng/mL -> 철 과다 위험
  - HbA1c >= 5.7% + 마그네슘 부족 -> 보강 후보

## 6. 비기능 요구사항
- 개인정보/민감정보 보호
  - 저장 시 암호화(At Rest), 전송 구간 TLS
  - 최소 수집 원칙, 보관 기간 정책
- 감사 가능성
  - 추천 근거 로그 저장
  - 규칙 버전 관리
- 책임 고지
  - 의료 진단/처방 대체 아님 문구 필수

## 7. 성공 지표
- 분석 완료율(입력 후 결과 확인): 70% 이상
- 성분 파싱 성공률: 85% 이상
- 사용자의 결과 신뢰도(자체 설문): 4.0/5.0 이상
